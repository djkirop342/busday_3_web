# 송민하의 밤하늘 · 10.17

`index.html` 하나만 있으면 됩니다. 더블클릭하면 바로 열려요.
노래 파일 `music.mp3`(오늘은 내가 말할게)는 이미 같은 폴더에 들어가 있습니다.

## 흐름

0. **시작 화면** — "화면을 눌러 시작하기"를 **마우스로 클릭**해야 넘어갑니다 (브라우저가 소리를 허용하는 순간이에요)
1. **인트로** — 이름이 한 글자씩 떠오름
2. **강아지자리** — 반짝이는 별을 코부터 순서대로 13번 클릭하면 앉아 있는 강아지가 그려집니다.
   누를 때마다 음이 한 단계씩 올라가고, 다 이으면 눈과 코가 살짝 나타나요
3. **케이크** — 초 5개를 눌러 불을 켠 뒤, 촛불을 하나씩 눌러 끕니다
4. **피날레** — 폭죽이 자동으로 터지고, 화면 아무 데나 누르면 그 자리에서 터집니다.
   **`편지 열기`를 누르는 순간 노래가 처음부터 재생되고**, 가사가 한 줄씩 편지에 나타납니다

왼쪽 아래 `건너뛰기 →` 로 장면을 넘길 수 있습니다 (테스트용).

## 소리

- **노래** — 편지를 열 때 시작합니다. 오른쪽 아래 플레이어로 재생/정지·볼륨 조절
- **효과음** — 파일 없이 브라우저가 직접 만들어 냅니다 (별 소리, 촛불 켜기/끄기, 폭죽 발사·폭발, 종이 넘기는 소리, 클릭음).
  플레이어 옆 `♪` 버튼으로 끌 수 있어요

## 가사 싱크 맞추기 (중요)

지금은 노래 길이(4분 37초)에 맞춰 가사를 **자동 분배**해 둔 상태입니다. 대략 흘러가지만 정확하진 않아요.
정확히 맞추려면 한 번만 이 작업을 해주세요. 2~3분이면 됩니다.

1. 주소 뒤에 `?sync` 를 붙여서 엽니다
   예) `file:///.../index.html?sync`
2. 시작 화면을 클릭하면 자동으로 피날레 + 편지 + 노래가 시작됩니다
3. 노래를 들으면서, **각 가사가 시작되는 순간마다 스페이스바**를 누릅니다
   - 왼쪽 위 패널에 다음에 나올 가사가 보입니다
   - 잘못 눌렀으면 **Backspace** 로 한 칸 되돌리기
4. 끝나면 패널 아래 칸에 `[12.4, 17.1, ...]` 같은 숫자 배열이 나옵니다. 전체 복사
5. `index.html` 안에서 `lyricTimes: []` 를 찾아 그 안에 붙여넣기

```js
lyricTimes: [12.4, 17.1, 21.8, ...],
```

이제 가사가 노래와 정확히 맞아떨어집니다.

### 대충만 맞추고 싶다면

`lyricTimes` 는 그대로 두고 아래 두 값만 조절해도 꽤 비슷해집니다.

```js
introSec: 12,   // 첫 가사가 나오기 전 전주 길이(초)
outroSec: 14,   // 마지막 가사 이후 남는 후주 길이(초)
```

## 내용 고치기

`index.html` 안의 `const CONFIG = { ... }` 부분만 고치면 됩니다.

- `name`, `dateLabel` — 이름과 날짜
- `stars[].msg` — 별을 하나 누를 때마다 나오는 문장 / `stars[].x`, `y` — 별 위치 (가로 0~100, 세로 0~70)
- `lines` — `[별A, 별B, 휘어지는 정도]`. 세 번째 값이 0이면 직선, 크면 더 둥글게 휩니다 (부호는 휘는 방향)
- `cake.count` — 초 개수
- `finale.letter` — 가사. `''` 는 빈 줄, `'*줄'` 은 후렴(금색 + 폭죽), `'**줄'` 은 마지막 큰 줄

## 로컬 서버로 열기 (선택)

`file://` 로 그냥 열어도 전부 동작합니다. 서버로 띄우고 싶다면:

```bash
cd "이 폴더"
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000  (싱크 모드는 http://localhost:8000/?sync)
```
